## Selected work

**Agricultural monitoring platform** — Afrostain Farm Tech (production)
FastAPI microservices and a Next.js front-end that bring Sentinel-2 satellite imagery, weather data and an LLM advisory assistant into one workflow for farmers. I own deployment (Docker Compose, Nginx load balancing, migration to HTTPS), authentication and the LLM service's caching and background workers.

**[Kombi Route Mapper](https://github.com/Leon-Mangwana/KOMBI-MAPPER)** — crowdsourced mapping of Harare's informal minibus network
GPS traces recorded by a Vue 3 PWA, cleaned and map-matched with OSRM, clustered into routes and stops, exported as a GTFS feed. FastAPI + PostGIS + Docker, with per-directory CI.

**[Campus Safety App](https://github.com/Leon-Mangwana/CampusSafetyApp)** — cross-platform incident reporting and SOS for university campuses
React Native/Expo app with a Node.js backend on Firebase: incident heatmaps, hold-to-activate SOS with live GPS, push alerts and a security-officer dashboard.
